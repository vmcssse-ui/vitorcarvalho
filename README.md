# Dr Vitor Carvalho — professional site

Static site, no build step. Open `index.html` or serve the folder. Built October 2026.

- `index.html` … `contact.html` — the seven pages, plus `decks.html` (lesson-deck downloads) and `404.html`.
- `evaluation.html` — the pre-registered evaluation (six measures, thresholds, decision rules; baseline and result columns empty until taken). Amended only by dated change-log entries.
- `what-went-wrong.html` — the public error log, dated entries newest first.
- `units/` — the five Ad Astra exemplar units (engine in `units/assets/`, one `manifest.js` per unit).
- `decks/` — 29 lesson decks (PowerPoint), one per chapter.
- `docs/` — *Adaptive by Design* report (PDF) and pitch (PPTX).
- `js/site.js` → `SITE_CONFIG` holds the LinkedIn URL and public email. Until set, the site shows
  "Email address to follow" and the LinkedIn button points at the contact page.
