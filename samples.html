Work you can open

Five exemplar units in the core subjects, the live course portals behind the case study, and the documents. Nothing here asks for an account, and nothing tracks you.

Core-subject exemplars · in build, October 2026

Five units, one model

One unit each in English Language, English Literature, Maths, Combined Science and Triple Science, built from the departments' own lesson decks on the four-step model: a read-along ebook for pre-teaching, then adaptive modules from Support to Stretch that end on the same task. Each is for specialist review before any wider use.

Live elsewhere

The work in use

Course sites built with the Edu.Ai Ecosystem framework, designed so that exam-board material stays off the public layer. An August 2026 audit found some A-level pages carrying past-paper wording; those are being corrected, and a checking tool now runs before publication.
